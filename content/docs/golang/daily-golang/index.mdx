本系列按 **课次**（`lesson-01`、`lesson-02` …）从 0 系统学习 Go。

- 学习路线定义在 `task/daily-golang/syllabus.json`（共 20 课）
- 每天定时任务生成一篇可独立阅读的文章
- 标题使用精简主题（如 `Go 环境安装与 hello world`），课次写在 frontmatter `lesson` 字段

## 定时任务

```bash
bash task/daily-golang/scripts/generate-daily-golang.sh
```

详见 `task/daily-golang/README.md`。
